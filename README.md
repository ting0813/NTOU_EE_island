# NTOU_EE_island

海大電機島 是一個以台灣海洋大學電機系大學部必修課程為內容的互動式網頁，整體是一座被海環繞的島，分成四個島區：
大一築基、大二電路、大三訊號、大四領域，中間是廣場，路徑相連。
共 33 門課，每門是一棟建築，屋頂顏色代表年級。
每個年級有 3 位同學在自己的島區裡走來走去，頭上標著年級數字。
系主任站在廣場中央。

互動方式
點建築：鏡頭拉近，顯示年級學期、先修與後續課程，並畫出流動的虛線連到相關建築，其他建築會變淡。同年級的同學會跑去那棟建築。
點小人：同學停下來，系主任走過去，依他的年級與目的地說話。
點系主任：開始七步導覽，依序介紹大一到大四、六大領域和輔系，鏡頭會跟著移動。
點島區標籤：鏡頭拉近到該年級。
上方工具列：
試選領域核心，可在「六選三」與「六選四」之間切換，選中的課程會發光。
開啟輔系模式，只亮出輔系必修課，並顯示學分說明。
暫停小人。
三種檢視：全景（地圖）、清單（依年級學期分組）、時間（八個學期的橫向排列），清單和時間裡點課程會跳回地圖。
